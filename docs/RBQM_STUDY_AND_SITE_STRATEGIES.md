# 研究级策略与中心级策略

本文只用完全合成的例子。研究编号是 `SYN-STUDY-001`，中心编号是 `SYN-SITE-*`。这些数字不是真实临床试验监查证据。

## 研究级策略（QTL）

研究级策略看的是整项合成研究，不把某一个中心单独拿出来下结论。

它管的是关键质量容忍限。当前合成例子是「重要方案偏离比例」：行动阈 `0.125`，对应阈值版本 `v1`。固定批次里的汇总值也是 `0.125`，所以系统登记一条研究级风险 `RSK-QTL-001`，状态是 `Detected`。

输入：

- 合成研究 `SYN-STUDY-001` 和关键质量因素 `CTQ-PD`
- 可能性、可检出性、影响度和权重
- 已批准的阈值版本，以及这批指标的 `inputBatchHash`
- 盲态标记。带未授权破盲分组的行会被拒绝，不会进入常规视图

人工决定点：

- 中央监查员确认这是不是一条有效的研究级信号
- 质量负责人决定是否批准新的阈值版本；预警阈大于等于行动阈，或权重为负，版本不会保存
- 关闭前必须有人写下根因、责任人和有效性复核

## 中心级策略（KRI）

中心级策略看的是单个合成中心相对阈值的偏离，用来决定要不要对这个中心采取成比例的监查行动。

当前合成例子是「知情同意签署合规性」。中心级 KRI 的行动阈是 `3.0 SD`。`SYN-SITE-101` 的固定值是 `3.5 SD`，所以系统登记 `RSK-KRI-101`。同一个种子再次生成时，风险编号、指标值和批次哈希不变。

输入：

- 合成中心编号、访视窗口和该中心的指标
- 与研究级相同的关键质量因素和阈值版本
- 中心对比图使用种子 `42` 的固定序列，不在页面上临时抽随机数

人工决定点：

- 人填写根因后，信号才能从 `Detected` 进入 `Triaged` 或 `Under_RCA`
- 人指定责任人、到期日和行动说明后，才能进入 `Action_In_Progress`
- 人记录有效性复核后，才能关闭。缺任何一项时状态保持不变，并返回明确错误

两条策略共用一条状态机：`Detected → Triaged/Under_RCA → Action_In_Progress → Effectiveness_Check → Closed`。研究级回答「整项研究有没有越过容忍限」，中心级回答「哪一个合成中心需要跟进」。自动化评分不代替这些人工决定。

## 反复越界只生成一条待确认候选

同一合成中心、同一指标要越过该中心级指标的行动界限至少两次，才生成一条研究级候选。候选状态是 `pending_confirmation`。再越界只增加次数，不生成第二条。单次越界、只到预警界限、换一个中心或换一个指标，都不算这一条的反复越界。同一条观察值（同一研究、中心、指标、数值和日期）再次提交只保留一次，不会因此生成候选。

人不确认时，已确认的研究级列表保持为空，`/api/rbqm/risks` 里的研究级 QTL 也不增加。确认只把这一条标成 `confirmed`，仍不写入研究级 QTL 信号。缺根因、责任人或有效性复核时，原有风险仍然不能关闭。这条候选读 RBQM 中心级界限，不读 CtQ 计划文件，也不改百分比判断。
